## ➕ Python Arithmetic Operators

Python provides several arithmetic operators to perform mathematical operations.

---

### 🧾 Table Summary

| Operator | Name             | Description                                | Example   | Result |
|----------|------------------|--------------------------------------------|-----------|--------|
| `+`      | Addition          | Adds two values                            | `5 + 3`   | `8`    |
| `-`      | Subtraction       | Subtracts right operand from left          | `5 - 3`   | `2`    |
| `*`      | Multiplication    | Multiplies two values                      | `5 * 3`   | `15`   |
| `/`      | Division          | Divides left by right (float result)       | `5 / 2`   | `2.5`  |
| `//`     | Floor Division    | Integer division, discards fractional part | `5 // 2`  | `2`    |
| `%`      | Modulus           | Returns remainder of division              | `5 % 2`   | `1`    |
| `**`     | Exponentiation    | Raises power (left^right)                  | `2 ** 3`  | `8`    |

---

## 🧪 Examples Explained

### 1. ➕ Addition (`+`)
Adds two numbers.

```python
a = 5
b = 3
print(a + b)  # Output: 8
```
### 2. ➖ Subtraction (`-`)
Subtracts one number from another.
```python
a = 5
b = 3
print(a - b)  # Output: 2
```

### 3. ✖️ Multiplication (`*`)
Multiplies two numbers.
```python
a = 5
b = 3
print(a * b)  # Output: 15
```

### 4. ➗ Division (`/`)
Divides and returns a floating-point result.
```python
a = 5
b = 2
print(a / b)  # Output: 2.5
```
### 5. 🧮 Floor Division (`//`)
Divides and returns an integer result (removes decimals).
```python
a = 5
b = 2
print(a // b)  # Output: 2
```

### 6. 🔁 Modulus (`%`)
Gives the remainder of a division.
```python
a = 5
b = 2
print(a % b)  # Output: 1
```
### 7. 🔼 Exponentiation (`**`)
Raises one number to the power of another.
```python
a = 2
b = 3
print(a ** b)  # Output: 8
```

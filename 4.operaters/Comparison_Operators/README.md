## 🔍 Python Comparison Operators

Comparison operators are used to compare two values. They return Boolean values: `True` or `False`.

---

### 📊 Comparison Operators Table

| Operator | Name               | Description                                   | Example (`a=10`, `b=20`) |
|----------|--------------------|-----------------------------------------------|---------------------------|
| `==`     | Equal to           | Returns True if values are equal              | `a == b` → `False`        |
| `!=`     | Not equal to       | Returns True if values are not equal          | `a != b` → `True`         |
| `>`      | Greater than       | True if left is greater than right            | `a > b` → `False`         |
| `<`      | Less than          | True if left is less than right               | `a < b` → `True`          |
| `>=`     | Greater than equal | True if left is greater or equal to right     | `a >= b` → `False`        |
| `<=`     | Less than equal    | True if left is less than or equal to right   | `a <= b` → `True`         |

---

## ✅ Examples

### 1. `==` Equal to
```python
a = 10
b = 20
print(a == b)  # False
```
### 2. `!=` Not equal to
```python
a = 10
b = 20
print(a != b)  # True
```

### 3. `>` Greater than
```python
a = 10
b = 20
print(a > b)   # False
```
### 4. `<` Less than
```python
a = 10
b = 20
print(a < b)   # True
```
   
### 5. `>=` Greater than or equal to
```python
a = 10
b = 20
print(a >= b)  # False
```
   
### 6. `<=` Less than or equal to
```python
a = 10
b = 20
print(a <= b)  # True
```
